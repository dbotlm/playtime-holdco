Complete REST API Documentation & Console

All endpoints available on the backend server for complete content administration

GET /api/content

Retrieve the complete site payload (meta, hero, portfolio, footer, press, inquiries) in a single JSON response.

curl -X GET http://localhost:8888/api/content

                


                
                

                    

                        GET
                        /api/portfolio
                    

                    
Fetch the ordered list of all portfolio startup companies.

                    
curl -X GET http://localhost:8888/api/portfolio

                    
                    

                


                
                

                    

                        POST
                        /api/portfolio
                    

                    
Create and append a new portfolio company to the holding showcase.

                    
curl -X POST http://localhost:8888/api/portfolio -H "Content-Type: application/json" -d '{"name":"Sample AI","tagline":"Next-gen intelligence","url":"https://example.com","logoUrl":"...","bgImageUrl":"..."}'

                


                
                

                    

                        PUT
                        /api/portfolio/{id}
                    

                    
Update any property (name, tagline, website, background image, logo) of an existing startup.

                    
curl -X PUT http://localhost:8888/api/portfolio/field-ai -H "Content-Type: application/json" -d '{"tagline":"Autonomous brains for field robots"}'

                


                
                

                    

                        DELETE
                        /api/portfolio/{id}
                    

                    
Delete a company from the portfolio database.

                    
curl -X DELETE http://localhost:8888/api/portfolio/{id}

                


                
                

                    

                        GET
                        /api/hero
                        PUT
                        /api/hero
                    

                    
Inspect or modify the hero headlines and brand logo URL.

                    
curl -X PUT http://localhost:8888/api/hero -H "Content-Type: application/json" -d '{"titlePart1":"At the intersection","titlePart2":"of Sports & Technology"}'

                    
                    

                


                
                

                    

                        GET
                        /api/press
                    

                    
Retrieve all media press highlights and external features.

                    
curl -X GET http://localhost:8888/api/press

                    
                    

                


                
                

                    

                        GET
                        /api/footer
                        PUT
                        /api/footer
                    

                    
Inspect or update footer email, logo, and social media handles (Twitter, Instagram, LinkedIn).

                    
                    

                


                
                

                    

                        POST
                        /api/reset
                    

                    
Factory reset all data back to the 100% original Play Time VC dataset.

                    
curl -X POST http://localhost:8888/api/reset
